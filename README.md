# bmp-trace

A Rust port of [Potrace](https://potrace.sourceforge.net/index.html).

## Installation

### As a dependency crate

```sh
$ cargo add bmp-trace
```

### As a standalone CLI tool

```sh
$ cargo install bmp-trace -F cli
```
